# Задача 7. Подтверждение выхода — промт для разработчика

Дизайнер не нужен, тексты даны ниже. Стиль как в `ui_deadlines.md`.

## Проблема (сверено с кодом)

- Кнопка «🚪 Выйти» (`callback logout` → `commands.button_callback` → `auth.logout`) сразу выполняет выход, подтверждения нет. Кнопка стоит в главном меню рядом с часто нажимаемыми, поэтому нажать её случайно легко.
- Последствия выхода (`auth_service.delete_user`) серьёзнее, чем выглядят: ставится `is_verified = False`, после этого перестают приходить **все** рассылки (дайджест, напоминания, дедлайны, объявления), а чтобы вернуться, нужен повторный вход с кодом на почту. Настройки и прогресс при этом сохраняются.
- Попутный баг: напоминания «за 15 мин», уже поставленные в очередь на сегодня, после выхода всё равно приходят. `_send_reminder` проверяет только выбор предметов, а `is_verified` не смотрит.

## 1. Экран подтверждения

Кнопка «🚪 Выйти» больше не выполняет выход, а открывает экран подтверждения (`logout`):

```html
🚪 <b>Выйти из аккаунта?</b>
Уведомления перестанут приходить. Настройки и прогресс сохранятся, но для входа снова понадобится код на почту.
```
```
[ Да, выйти ] [ ◀️ Остаться ]
```
- `Да, выйти` → `logout_confirm` → выход (текущий `auth.logout`).
- `◀️ Остаться` → `back_to_menu`, главное меню без изменений.
- Экран выводится через `show_screen`, как и остальные.

## 2. Команда `/logout`

- Работает так же: показывает тот же экран подтверждения, а сам выход происходит только после кнопки.

## 3. Экран после выхода

```html
👋 <b>Вы вышли из аккаунта</b>
Уведомления больше не придут. Чтобы вернуться — войдите снова.
```
```
[ 🔐 Авторизоваться ]
```
- Сейчас после выхода остаётся текст без кнопок, и пользователь в тупике. Кнопка ведёт в существующий вход (`login`).

## 4. Баг с напоминаниями

- В `auth.logout` после `delete_user` вызвать `replan_reminders_for_user(context.job_queue, user_id)`. Нужно убедиться, что он не ставит напоминания пользователю с `is_verified = False`.
- В `_send_reminder` дополнительно проверять `is_verified` перед отправкой: это страховка на случай, если очередь уже собрана.

## 5. Callback'и

| Действие | callback_data |
|---|---|
| экран подтверждения | `logout` (как сейчас) |
| подтвердить | `logout_confirm` |
| остаться | `back_to_menu` (существующий) |

- В `commands.button_callback` ветку `logout` перевести на показ подтверждения, добавить ветку `logout_confirm`.

## Критерии готовности

- Одно нажатие «🚪 Выйти» не выходит из аккаунта.
- «Остаться» возвращает в меню, всё работает как раньше.
- «Да, выйти» выходит, после этого виден экран с кнопкой «🔐 Авторизоваться».
- `/logout` ведёт себя так же, как кнопка.
- Выход в 12:00 → напоминание за 15 минут на 14:00 не приходит.
- После повторного входа настройки уведомлений, «Мои предметы» и прогресс на месте.
