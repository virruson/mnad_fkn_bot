# Задача 8. Сданное — вычеркнуть в дедлайнах и убрать с графика

Промт для разработчика. Дизайнер не нужен: правило отображения описано ниже и следует стилю `ui_deadlines.md`.

## Зачем

Студент отметил в «📈 Мой прогресс», что сдал задание. В «⏳ Дедлайнах» оно всё равно висит как актуальное, с «❗» и «осталось N дн», и в графике тоже. Нужно, чтобы сданное:
- в карточке предмета было **вычеркнуто**;
- на **графике не показывалось**;
- не делало предмет срочным в списке.

## Что уже есть (сверено с кодом)

- Отметки хранятся в `user_progress` (`done_at IS NOT NULL` — сдано).
- В `services/deadlines.py` есть `without_done(deadlines, done)`. Она убирает сданные дедлайны **и их пары «… жёсткий»** (через `hard_base_key`). Сейчас её использует только утренняя рассылка в `scheduler.py`: там же собирается `done_by_user`.
- Карточка (`render_subject_card` / `format_deadline_line`) и список предметов (`build_subject_buttons`) про отметки не знают, они одинаковы для всех.
- График (`show_deadline_chart`) уже фильтрует по «Моим предметам» (`visible_deadlines`), но сданное не отбрасывает. Ключ кэша (`cache_key`) строится по набору элементов в окне, поэтому после фильтрации он станет разным сам.
- Жёсткие сроки — отдельные строки (`№1` + `№1 жёсткий (…)`). На графике они склеиваются в одну полосу (`Item.hard`).

## 1. Общие хелперы (`services/deadlines.py`)

- `get_done_deadlines(db, user_id) -> list[Deadline]` — вынести запрос из `scheduler.py`, чтобы одна функция использовалась везде.
- `done_ids(deadlines, done) -> set[int]` — id сданных плюс их пары «жёсткий». Это дополнение к `without_done`: `without_done(ds, done) == [d for d in ds if d.id not in done_ids(ds, done)]`. Логику пар не дублировать, переиспользовать `hard_base_key`.
- Пользователь не авторизован или не найден — набор сданного пустой, всё работает как раньше.

## 2. Карточка предмета

Сданная строка вычеркивается, перед ней `✅`. «❗» и «осталось» не пишутся:

```html
📝 <b>ДЗ</b>
✅ <s>№1 · <b>14.10</b></s>
<s>№1 жёсткий (−1 балл/сутки после 14.10) · <b>21.10</b></s>
№2 · <b>28.10</b> · <i>осталось 16 дн</i>
```
- `✅` ставится только на ту строку, которую студент отметил сам. Её пара «жёсткий» просто вычеркивается, без `✅`.
- Прошедшие несданные строки остаются вычеркнутыми без `✅`, как сейчас. По `✅` видно, что сдал, а не просто срок прошёл.
- То же для этапов ВКР (дата впереди): `✅ <s><b>20.10</b> · Выбор научных руководителей</s>`.
- Сокрытие лишних строк (`BLOCK_MAX_LINES = 4`): сданные считаются наравне с прошедшими, в первую очередь скрываются самые старые из них. Подпись `<i>ещё N прошедших</i>` заменить на `<i>ещё N закрытых</i>`: она покрывает и прошедшие, и сданные.
- `render_subject_card` и `format_deadline_line` получают параметр `done: set[int]`. Обработчик `show_subject_card` берёт его через хелперы из п. 1 для текущего пользователя.

## 3. Список предметов «⏳ Дедлайны»

- В `build_subject_buttons` сданные дедлайны не участвуют ни в «❗», ни в сортировке по ближайшему сроку. Проще всего передавать туда `without_done(...)`.
- Если у предмета сдано всё будущее, он уходит в группу «без будущих дедлайнов», как сейчас.

## 4. График «📊 Все на графике»

- Перед `split_items` убрать сданное: `deadlines = without_done(visible_deadlines(...), done)`. Тогда сданное пропадёт и с картинки, и из подписи («Ближайший», «Позже: …», «и ещё N»).
- Если «№1» сдан, его пара «жёсткий» тоже не показывается: `without_done` это уже делает.
- Если в окне ничего не осталось, но до фильтрации что-то было, то есть всё сдано, вместо обычного пустого текста показать:
  ```html
  ✅ <b>Всё на 2 недели сдано</b>
  ```
  а ниже, если есть, ту же строку «Позже: …», что и сейчас.
- Кэш трогать не нужно: набор в окне другой, значит, ключ другой.

## 5. Что не меняется

- Утренняя рассылка «за 4, 2, 1 дн» уже пропускает сданное (`without_done`).
- «📈 Мой прогресс» — источник отметок, его не трогаем.
- Строки с ролью `hidden` (например, пересдачи) в дедлайнах показываются как раньше. Отметка «Тест №1» пересдачу не закрывает: это разные события.

## 6. Обратимость

- Отметки не кэшируются: каждый экран читает их заново. Если студент нажал «↩️ Не сдано», строка в карточке снова становится активной, а на графике полоса возвращается.

## Критерии готовности

- Студент отметил ДЗ №1 RecSys:
  - в карточке RecSys: `✅` и вычеркнуто, без «осталось»;
  - на графике полосы ДЗ №1 нет, в подписи его тоже нет;
  - если это был единственный срочный дедлайн, «❗» с кнопки RecSys пропадает.
- Отметил «№1» у ПМО: строка «№1 жёсткий …» тоже вычеркнута, на графике нет ни основной, ни штрафной полосы.
- Другой студент, у которого ничего не отмечено, видит карточку и график как раньше.
- «↩️ Не сдано» возвращает всё назад.
- Всё в окне сдано → на графике текст «Всё на 2 недели сдано».
- Тесты на `done_ids`: пара «жёсткий», бонус, этап ВКР, пустой набор.
