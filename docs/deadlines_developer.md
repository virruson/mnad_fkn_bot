# Задача 1. Дедлайны и уведомления — промт для разработчика

## Контекст

Telegram-бот `mnad_fkn_bot`: Python (python-telegram-bot), PostgreSQL, SQLAlchemy/Alembic, docker-compose.

- Расписание загружается из Google Sheet скриптом `scripts/import_schedule.py`.
- Утренний дайджест в 10:00 МСК и напоминания за 15 мин находятся в `bot/services/scheduler.py`.
- Экраны выводятся через `bot/utils/ui.show_screen`: одно сообщение на чат, при переходах оно редактируется.

Главный принцип: минимализм, никаких лишних сущностей.

Связанные задачи, которые делаются после этой: «Объявления» (`announcements_developer.md`) и «График дедлайнов» (`deadline_chart_developer.md`).

---

## 1. Переименование

- Кнопку главного меню «📚 Задания» заменить на «⏰ Дедлайны», callback `tasks` на `deadlines`.
- Команду `/tasks` заменить на `/deadlines`, `/tasks` оставить алиасом.
- Файл `handlers/tasks.py` переименовать в `handlers/deadlines.py`, заглушку удалить.
- Кнопку «📖 Предметы» не трогать.

## 2. Данные (одна миграция)

- Новая таблица `modules`: `id, name, start_date, end_date`. Текущий модуль тот, в диапазон которого попадает today.
- Новая таблица `deadlines`:
  - `id`
  - `subject_id → subjects`
  - `kind`: `'hw' | 'quiz' | 'test' | 'exam' | 'vkr'`
  - `title`
  - `due_date DATE`, `due_time TIME NULL` (если время пустое, считать 23:59)
  - `hard_due_date DATE NULL`: окно сдачи со штрафом
  - `penalty TEXT NULL`: текст штрафа, например «−1 балл/сутки»
  - `is_tentative BOOL DEFAULT false`: дата ориентировочная
- В `subjects` добавить `grading_formula TEXT NULL`.
- В `users`:
  - заменить `notifications_enabled` на два флага, `digest_enabled` и `reminders_enabled`. При миграции оба получают старое значение, чтобы текущие подписки не слетели;
  - добавить `deadlines_enabled BOOL NOT NULL DEFAULT false`.
- Дедлайны общие для всех групп, привязки к `stream` нет.

## 3. Импорт

Скрипт `scripts/import_deadlines.py` по образцу `import_schedule.py`: upsert, флаг `--dry-run`, ничего не удаляет.

- Вкладка «Дедлайны»: `Предмет | Тип (ДЗ/Квиз/КР/Экзамен/ВКР) | Название | Дата | Время | Жёсткий срок | Штраф | Ориентировочно`. Ключ upsert: предмет + тип + название.
- Вкладка «Формулы»: `Предмет | Формула`.
- Предмет ищется по точному названию. Если не найден: warning, строка пропускается, новый предмет не создаётся.

## 4. Экран «⏰ Дедлайны»

- Кнопки предметов, по одной в строке. Внизу «🏠 Главное меню».
- Предмет попадает в список, если у него есть занятия в текущем модуле **или** хотя бы один дедлайн с `due_date >= today`. Так видна ВКР, у которой нет занятий.
- Если до ближайшего дедлайна предмета меньше 2 дней (сегодня или завтра), к кнопке добавляется «❗».
- Если показать нечего, выводится «нет информации».

## 5. Карточка предмета (`deadlines_subj_<id>`, `parse_mode=HTML`)

- Блоки в порядке: ДЗ, Квизы, КР, Экзамен, Этапы ВКР, Формула оценивания. Внутри блока сортировка по дате. Пустые блоки не выводятся.
- Строка дедлайна: название, дата с днём недели, время и «осталось N дн». В сам день дедлайна вместо остатка пишется «сегодня».
- Если до срока меньше 2 дней, строка начинается с «❗».
- Прошедший дедлайн зачёркнут (`<s>`), «осталось» у него не пишется.
- Жёсткий срок: «до 20.10 · со штрафом до 25.10 (−1 балл/сутки)».
- Ориентировочная дата: «~25.10 (ориентировочно)».
- Формула выводится как есть: `Итог = 0.3·ДЗ + 0.2·Квизы + 0.5·КР`.
- Если у предмета ничего нет, выводится «нет информации».
- Кнопки: «◀️ К предметам», «🏠 Главное меню».

## 6. Меню «🔔 Уведомления»

Три независимых переключателя. Нажатие инвертирует флаг и перерисовывает меню.

| Кнопка | Флаг |
|---|---|
| Расписание на день · 10:00 | `digest_enabled` |
| Напоминание за 15 мин | `reminders_enabled` |
| Дедлайны · за 4, 2, 1 дн | `deadlines_enabled` |

- Список переключателей держать в одном месте (список «подпись → флаг»), чтобы новые добавлялись одной строкой. Задача «Объявления» добавит четвёртый.
- Под переключателями кнопка «👥 Группа: …». Она открывает существующий выбор группы, после выбора бот возвращает пользователя в меню.
- Первым двум переключателям нужна группа. Если группа не выбрана, при включении сначала открывается её выбор.
- Кнопки «Настроить уведомления» и «Отключить уведомления» удалить.
- В `scheduler.py` дайджест отправлять по `digest_enabled`, напоминания планировать по `reminders_enabled`. Сейчас напоминания ставятся внутри `daily_digest`; их нужно развязать, чтобы они работали независимо.

## 7. Рассылка дедлайнов

- Новый job `deadline_digest`, `run_daily` в 10:00 МСК.
- Отбираются дедлайны, у которых `due_date - today` равно ровно 4, 2 или 1, по всем предметам.
- Каждому пользователю с `deadlines_enabled` уходит одно сообщение с группами «завтра / через 2 дня / через 4 дня».
- Если в этот день подходящих дедлайнов нет, ничего не отправляется. Ежедневной рассылки нет.
- Сообщение текстовое, чтобы его было видно в push. Оно фоновое и идёт мимо `show_screen`.
- Ошибку отправки конкретному пользователю залогировать и продолжить цикл.

## Критерии готовности

- Миграция накатывается и откатывается, текущие подписки пользователей сохраняются.
- `--dry-run` импорта показывает, что будет загружено.
- Все экраны открываются из меню и помещаются в одно сообщение.
- ВКР без занятий видна в списке предметов.
- Ручной вызов `deadline_digest` на тестовой дате отправляет сообщение только за 4, 2 и 1 день до срока.
- Тексты, эмодзи и вид переключателей взяты из макетов дизайнера (`deadlines_designer.md`).
