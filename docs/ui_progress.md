# UI: «Мой прогресс»

Макеты текстов бота для задачи `progress_designer.md`. Разметка — Telegram HTML (`parse_mode=HTML`): `<b>`, `<i>`, `<s>`, `<code>`, `<pre>`.
Кнопки обозначены `[ … ]`; кнопки в одной строке стоят рядом: `[ A ] [ B ]`.
Пример построен на дате вс 11.10.2026 и реальных данных из `scripts/deadlines.json`.
Тексты и разметку переносить дословно; цифры в примерах — образец.

## Общие правила

- Стиль тот же, что в `ui_deadlines.md`: не больше одной эмодзи на строку, пустое состояние `<i>нет информации</i>`, возврат кнопкой `◀️ Назад` (как в карточке дедлайнов).
- Значки блоков те же, что в карточке дедлайнов: 📝 ДЗ, 🧠 Квизы/КР, 📋 КР, 🎓 Экзамен, 📌 Этапы. Новый тип: 🛠 Проект.
- Статус: `☐` не сдано, `✅` сдано. Оценка пишется сразу после галочки жирным: `✅ <b>8</b>`. Как у переключателей в «Уведомлениях».
- Оценки пишутся как введены: `8`, `7.5` (без `.0` у целых). Средние по компоненту — один знак: `8.0`. Накоп и итог — два знака: `2.70`, `7.85`. Разделитель — точка.
- В подписях кнопок HTML не работает; на кнопке активности — только статус и короткое название, без значка типа.
- В прогрессе не показываются служебные строки дедлайнов: жёсткие сроки («№1 жёсткий …») и пересдачи. Бонусные задания показываются со словом `<i>бонус</i>` и в накоп не входят.

## 0. Главное меню

```
[ 📅 Расписание ] [ 🔔 Уведомления ]
[ ⏳ Дедлайны ] [ 📈 Мой прогресс ]
[ 🚪 Выйти ]
```
- «📈 Мой прогресс» встаёт на место заглушки «📖 Предметы». Остальное без изменений.

## 1. Экран «📈 Мой прогресс»

```html
📈 <b>Мой прогресс</b>
Сдано и накоп по формуле

Продвинутое МО — ✅ 2/5 · <b>2.70</b> из 7.0
RecSys — ✅ 1/1 · <b>2.61</b> из 5.8
Обучение с подкреплением — ✅ 0/1 · <b>0.00</b> из 10.0
Временные ряды — ✅ 3/9 · формула не задана
ВКР — ✅ 0/13
```
```
[ Продвинутое МО ]
[ RecSys ]
[ Обучение с подкреплением ]
[ Временные ряды ]
[ ВКР ]
[ ◀️ Назад ]
```
- Строка: `Короткое название — ✅ сдано/всего · накоп из максимума`.
  - «всего» — активности без бонусов и служебных строк.
  - Нет весов формулы → вместо накопа `формула не задана`.
  - У ВКР (только этапы) накопа нет — строка заканчивается счётчиком.
- Порядок предметов и кнопок — как на экране «⏳ Дедлайны», но без «❗»: здесь не про срочность. ВКР последней.
- Нет предметов: вместо подзаголовка и списка `<i>нет информации</i>`, кнопка только `◀️ Назад`.
- `◀️ Назад` → главное меню.

### Правила экрана

- Заголовок — `📈` + полное название.
- Блоки и порядок — как в карточке дедлайнов (`KIND_BLOCKS`), 🛠 Проект — перед 🎓 Экзаменом. Пустые блоки не выводятся. Внутри блока — по дате.
- Строка активности: `статус [· оценка] · название · дата[, время]`. Время — только если не 23:59. У этапов ВКР дата впереди, как в карточке дедлайнов. У экзамена без названия — слово «Экзамен».
- Прошедшие и несданные строки не зачёркиваются и не помечаются: прогресс — это отметки студента, а не сроки.
- Блок «🧮 Накоп»:
  - формула текстом в `<code>`, как в карточке дедлайнов;
  - таблица в `<pre>`: строка на компонент формулы в порядке формулы, колонки выровнены пробелами. `компонент · средняя по оценённым · оценено N из M`. Нет оценок — `—`. Компонента нет в списке активностей — `— · нет в списке`;
  - `<b>Накоп: X</b> из Y` — всегда; `<b>Итог: Z</b>` — только если экзамен оценён;
  - пометка курсивом: пока нет итога — `неоценённое = 0, особые правила не учтены`; с итогом — `особые правила и округление — по правилам курса`.
- Нет весов формулы: блок «🧮 Накоп» = формула (если есть) + `<i>формула не задана — накоп не считается</i>`.
- ВКР: блоков, формулы и накопа нет; под заголовком `Отмечено N из M этапов`.

### Кнопки активностей

- Две в ряд, в порядке строк текста. Нечётная последняя — одна в ряду.
- Подпись: `статус название`, до 14 символов:
  - название начинается с «№» → короткий тип + номер: `ДЗ №1`, `Квиз №3`, `КР №1`, `Проект №1`;
  - иначе название без части в скобках: `Тест №2 (на занятии)` → `Тест №2`;
  - экзамен → `Экзамен`;
  - длиннее 14 → обрезать по символу с «…».
- Этапы ВКР — по одной в ряд, `статус дата · название`, до 28 символов с «…».
- Оценка на кнопку не выносится — она в тексте.

## 3. Выбор оценки

Открывается сразу после нажатия на несданную активность (она уже отмечена сданной).

```html
✅ <b>ДЗ №2</b> отмечено сданным
Продвинутое МО · срок 20.10

Оценка известна?
```
```
[ 4 ] [ 5 ] [ 6 ] [ 7 ]
[ 8 ] [ 9 ] [ 10 ] [ ✏️ Другая ]
[ Пока нет ] [ ↩️ Отменить ]
```
- Цифра → оценка сохранена, возврат на экран предмета, всплывающая подсказка `ДЗ №2: 8`.
- `Пока нет` → возврат на экран предмета, отметка остаётся, подсказка `ДЗ №2: сдано`.
- `↩️ Отменить` → отметка снимается (нажали по ошибке), возврат на экран предмета, подсказка `ДЗ №2: не сдано`.
- Бонусное задание — тот же экран, вторая строка: `Продвинутое МО · бонус, в накоп не входит`.
- Этапы ВКР этот экран не открывают: нажатие только переключает `☐ / ✅`, подсказка `Отмечено` / `Отметка снята`.
- Тот же экран для «Изменить оценку» (см. п. 4), только первая строка `<b>ДЗ №1</b> · сейчас <b>8</b>`, вопрос `Новая оценка?`, а внизу одна кнопка `◀️ Назад`.

## 4. Сданная активность

С оценкой:
```html
✅ <b>ДЗ №1</b> · оценка <b>8</b>
Продвинутое МО · срок 04.10
```
```
[ ✏️ Изменить оценку ]
[ 🗑 Убрать оценку ]
[ ↩️ Не сдано ]
[ ◀️ Назад ]
```

Без оценки:
```html
✅ <b>Тест №2</b> · оценки нет
Продвинутое МО · срок 17.10
```
```
[ ✏️ Поставить оценку ]
[ ↩️ Не сдано ]
[ ◀️ Назад ]
```
- `🗑 Убрать оценку` → оценка удаляется, отметка «сдано» остаётся, экран обновляется (вариант «без оценки»).
- `↩️ Не сдано` → снимаются отметка и оценка, возврат на экран предмета, подсказка `Тест №2: не сдано`.
- `◀️ Назад` → экран предмета.

## 5. Ввод оценки вручную (`✏️ Другая`)

Приглашение:
```html
✏️ Оценка за <b>ДЗ №2</b>
Отправьте число от 0 до 10, например <code>7.5</code>
/cancel — отмена
```

Неверный ввод (экран заменяется, ждём снова):
```html
✏️ Оценка за <b>ДЗ №2</b>
Нужно число от 0 до 10, например <code>7.5</code>
/cancel — отмена
```

Сохранено — открывается экран предмета, первой строкой:
```html
<i>Сохранено: ДЗ №2 — 7.5</i>

📈 <b>Продвинутое машинное обучение</b>
…
```
- Принимаются `7.5` и `7,5`; больше одного знака после запятой — округлить до одного.
- `/cancel` → экран предмета без строки «Сохранено», отметка «сдано» остаётся.

## 6. Пустые состояния

Предмет без весов формулы (отметки работают):
```html
📈 <b>Анализ и прогнозирование временных рядов</b>

📝 <b>ДЗ</b>
✅ · №1 · 11.10
…

🧮 <b>Накоп</b>
<code>Итог = 0.4·ДЗ + 0.2·Квизы + 0.4·ЭКЗ</code>
<i>формула не задана — накоп не считается</i>
```
(если нет и текста формулы — только курсивная строка)

Предмет без активностей:
```html
📈 <b>Алгоритмы и структуры данных</b>

<i>нет информации</i>
```
```
[ ◀️ Назад ]
```

## Легенда (дополнение к `ui_deadlines.md`)

| Значок | Где | Значение |
|---|---|---|
| 📈 | меню, заголовки | раздел «Мой прогресс» |
| 🛠 | блок | Проект (новый тип) |
| ☐ | строка, кнопка | не сдано |
| ✅ | строка, кнопка | сдано, оценки нет |
| ✅ **8** | строка | сдано, оценка 8 |
| 🧮 | блок | Накоп (в дедлайнах — Формула) |
| ✏️ | кнопка | ввести / изменить оценку |
| 🗑 | кнопка | убрать оценку |
| ↩️ | кнопка | снять отметку |
| *бонус* | строка | задание вне формулы, в накоп не входит |
