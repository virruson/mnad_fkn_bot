# UI: «Выбор модуля»

Макеты текстов бота для задачи `module_switch_designer.md`. Разметка — Telegram HTML (`parse_mode=HTML`): `<b>`, `<i>`, `<s>`, `<code>`.
Кнопки обозначены `[ … ]`; кнопки в одной строке стоят рядом: `[ A ] [ B ]`.
Пример построен на дате чт 05.11.2026: 5 модуль 05.09–01.11 (прошёл), 6 модуль 02.11–20.12 (идёт), 7 модуль 11.01–14.03 (ещё не начался). Даты 6 и 7 модуля — образец.
У студента в «Моих предметах» отмечены «Общие предметы», RecSys и «Обучение с подкреплением».
Тексты и разметку переносить дословно.

## Общие правила

- Значок модуля — 🗂. Он один и тот же в меню, на экране выбора, в плашке и в кнопке возврата.
- Статус модуля пишется одним словом: `текущий`, `архив`, `скоро`.
- Модуль называется так, как в `modules.name`: «5 модуль».
- Плашка показывается только в нетекущем модуле. В текущем модуле все экраны выглядят как сейчас.
- Уведомления, утренние рассылки и напоминания от выбора модуля не зависят и плашку не показывают.

## 1. Главное меню

Выбран текущий модуль:
```
[ 🗂 6 модуль · текущий ]
[ 📅 Расписание ] [ 🔔 Уведомления ]
[ ⏳ Дедлайны ] [ 📈 Мой прогресс ]
[ 💬 Обратная связь ] [ 🚪 Выйти ]
```

Выбран архивный:
```
[ 🗂 5 модуль · архив ]
…
```

Выбран будущий:
```
[ 🗂 7 модуль · скоро ]
…
```
- Кнопка первой строкой, на всю ширину. Остальные строки без изменений.
- Если в боте один модуль — кнопки нет.
- Текст главного меню не меняется.

## 2. Экран выбора модуля

```html
🗂 <b>Модуль</b>
Переключает дедлайны, прогресс, «Мои предметы» и расписание. Уведомления всегда приходят по текущему модулю.

5 модуль · 05.09 – 01.11
6 модуль · 02.11 – 20.12
7 модуль · 11.01 – 14.03
```
```
[ 5 модуль · архив ]
[ ✅ 6 модуль · текущий ]
[ 7 модуль · скоро ]
[ ◀️ Назад ]
```
- Модули по дате начала. Даты — в тексте, на кнопках — номер и статус: так подпись всегда влезает в 28 символов.
- ✅ — модуль, который сейчас открыт. У остальных отметки нет.
- Нажатие на модуль → подсказка (п. 7) и возврат в главное меню, кнопка модуля уже с новой подписью.
- `◀️ Назад` → главное меню.

## 3. Плашка «какой модуль открыт»

Одна строка, первой строкой экрана, над заголовком:
```html
🗂 Открыт <b>5 модуль</b> · архив
```
```html
🗂 Открыт <b>7 модуль</b> · скоро
```
- Не курсив и не ⚠️: это не ошибка, просто напоминание.
- На экранах с плашкой — кнопка быстрого возврата, над `◀️ Назад` / `🏠 Главное меню`:
```
[ 🗂 Вернуться в 6 модуль ]
```
  Она открывает текущий модуль и перерисовывает **тот же раздел** (не главное меню).

Сдано и накоп по формуле

- Порядок предметов — как в дедлайнах архива: по алфавиту, ВКР последней.
- Отметки и оценки в архиве работают как обычно: экраны предмета, выбора оценки и сданной активности — без изменений и без плашки.

Уведомления, расписание, дедлайны, график и прогресс — только по отмеченным.

```

[ ◀️ Назад ]
```

## 4. «⏳ Дедлайны» в архивном модуле

Список — см. п. 3. Отличия от текущего модуля:
- подсказка короче: `Выберите предмет`, без «· ❗ — меньше 2 дней»;
- «❗» на кнопках нет, даже если у сквозного курса есть будущий срок: срочное показывается в текущем модуле;
- кнопки «📊 Все на графике» нет;
- предметы по алфавиту короткого названия (сначала кириллица, потом латиница), ВКР последней.

Карточка предмета — как сейчас, без плашки:
```html
<b>RecSys</b>

📝 <b>ДЗ</b>
✅ <s>№1 · <b>21.10</b></s>
✅ <s>№2 · <b>24.10</b></s>

🎓 <b>Экзамен</b>
<s>Доклад · <b>31.10</b></s>

🧮 <b>Формула</b>
<code>Итог = 0.29·ДЗ_1 + 0.29·ДЗ_2 + 0.42·ЭКЗ (доклад) · округление арифметическое</code>
```
```
[ ✏️ Неточность? ]
[ ◀️ Назад ]
```
- Сданные — «✅» и зачёркнуто, прошедшие несданные — просто зачёркнуто. Всё как в текущем модуле, ничего нового.

## 5. «📅 Расписание» в нетекущем модуле

### Экран выбора

```html
🗂 Открыт <b>5 модуль</b> · архив
📅 <b>Расписание</b>
5 модуль · 05.09 – 01.11 · 9 недель
```
```
[ 📅 По неделям ]
[ 🗓 Указать период ]
[ 🗂 Вернуться в 6 модуль ]
[ ◀️ Назад ]
```
- «📅 По неделям» открывает неделю модуля, ближайшую к сегодняшней дате: в архиве — последнюю, в будущем модуле — первую.

### Неделя

```html
🗂 Открыт <b>5 модуль</b> · архив
📅 <b>Неделя 4 из 9</b> · 21.09 – 27.09

<b>пн 21.09</b>
18:10 Временные ряды · лекция
19:40 Временные ряды · семинар

<b>вт 22.09</b>
19:40 Обучение с подкреплением · лекция

<b>ср 23.09</b>
18:10 RecSys · лекция
19:40 RecSys · семинар
19:40 Обучение с подкреплением · семинар

<b>чт 24.09</b>
19:40 Обучение с подкреплением · лекция

<b>сб 26.09</b>
11:10 Глубинное обучение · лекция
13:00 Глубинное обучение · семинар
14:40 Продвинутое МО · лекция
16:20 Продвинутое МО · семинар
```
```
[ ◀️ Неделя 3 ] [ Неделя 5 ▶️ ]
[ 📅 К выбору периода ]
[ 🏠 Главное меню ]
```
- Строка занятия короткая: `время · короткое название · тип строчными`. Без преподавателя, потока и ссылки — это расписание для справки, на занятие по нему не идут.
- Дни без занятий не выводятся. Только «Мои предметы».
- Первая неделя — только `[ Неделя 2 ▶️ ]`, последняя — только `[ ◀️ Неделя 8 ]`.
- Неделя считается с понедельника. Первая — неделя, в которую попадает начало модуля (31.08 – 06.09), последняя — неделя с концом модуля (26.10 – 01.11).

Неделя без занятий (образец: в 5 модуле у этого студента таких недель нет; бывает в праздники или когда на неделе идут только неотмеченные маголего):
```html
🗂 Открыт <b>5 модуль</b> · архив
📅 <b>Неделя 8 из 9</b> · 19.10 – 25.10
<i>занятий нет</i>
```
Кнопки — как у обычной недели.
- Здесь не «нет информации»: расписание загружено, просто на этой неделе пусто.

## 6. Пустые состояния

В модуле нет дедлайнов («⏳ Дедлайны», «📈 Мой прогресс»):
```html
🗂 Открыт <b>7 модуль</b> · скоро
⏳ <b>Дедлайны</b>
<i>нет информации</i>
```
```
[ 🗂 Вернуться в 6 модуль ]
[ 🏠 Главное меню ]
```

В будущем модуле ещё не загружены предметы («📚 Мои предметы»):
```html
🗂 Открыт <b>7 модуль</b> · скоро
📚 <b>Мои предметы</b>
<i>нет информации</i>
```
```
[ 🗂 Вернуться в 6 модуль ]
[ ◀️ Назад ]
```

Расписание будущего модуля ещё не загружено:
```html
🗂 Открыт <b>7 модуль</b> · скоро
📅 <b>Расписание</b>
7 модуль · 11.01 – 14.03
<i>нет информации</i>
```
```
[ 🗂 Вернуться в 6 модуль ]
[ ◀️ Назад ]
```
- «По неделям» и «Указать период» не показываются, пока в модуле нет ни одного занятия.

## 7. Подсказки (`query.answer`)

| Когда | Текст |
|---|---|
| выбран архивный модуль | `Открыт 5 модуль · архив` |
| выбран будущий модуль | `Открыт 7 модуль · скоро` |
| выбран текущий модуль (в т. ч. «🗂 Вернуться в …») | `Открыт 6 модуль · текущий` |
| повторное нажатие на уже открытый модуль | `5 модуль уже открыт` |
| «📊 Все на графике» в нетекущем модуле (старая кнопка) | `График — только в текущем модуле` |
