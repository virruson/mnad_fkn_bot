# Задача 4. «Мой прогресс» — промт для дизайнера

## Контекст

Telegram-бот расписания магистратуры ВШЭ (МНАД). Интерфейс состоит только из текста, эмодзи и inline-кнопок. Главное требование — минимализм: всё должно читаться на телефоне с первого взгляда.

Новая функция «📈 Мой прогресс»: студент отмечает сданные активности по предмету (ДЗ, квизы, КР, экзамен, проект), ставит оценку, если она уже известна, и сразу видит свой накоп по формуле.

## Что уже есть и что берём без изменений

- Значки типов из раздела «Дедлайны»: 📝 ДЗ, 🧠 Квизы/КР, 📋 КР, 🎓 Экзамен, 📌 Этапы. Для нового типа «Проект» нужно подобрать один значок.
- Состояния отметок такие же, как у переключателей в «Уведомлениях»: `☐` не сдано, `✅` сдано.
- Короткие названия предметов (например, «Продвинутое МО») и пустое состояние «нет информации».
- Кнопка «📈 Мой прогресс» встаёт в главном меню на место заглушки «📖 Предметы».

## Что решено по логике (это не макет, но влияет на него)

- Нажатие на несданную активность сразу отмечает её сданной и открывает выбор оценки. Можно выбрать «Пока нет».
- Оценка по 10-балльной шкале, допускается один знак после запятой.
- **Накоп сейчас** считается по весам формулы без экзамена. Неоценённые активности идут как 0. Показывается в виде «4.9 из 7.0».
- **Итог** появляется только после того, как оценён экзамен.
- Особые правила формулы (автомат, бонусы, округление) в расчёт не входят, поэтому нужна короткая пометка об этом.
- Этапы ВКР можно только отметить сданными, оценки у них нет.

## Нужно сделать 6 текстовых макетов

Готовый текст с разметкой на реальных данных: «Продвинутое машинное обучение» с формулой `0.5·ДЗ + 0.2·КР + 0.3·ЭКЗ` и «RecSys» с формулой `0.29·ДЗ_1 + 0.29·ДЗ_2 + 0.42·ЭКЗ`.

1. **Экран «Мой прогресс»**: по строке на предмет (сколько сдано и накоп) и кнопки предметов.
2. **Прогресс по предмету**:
   - активности блоками по типам, у каждой статус: `☐`, `✅` или `✅ 8.5`;
   - формула;
   - по каждому компоненту средняя оценка и «оценено N из M»;
   - накоп «X из Y», а в варианте с оценённым экзаменом — итог;
   - кнопки активностей по две в ряд, подписи до ~14 символов (например, «📝 ДЗ №1»).

   Нужны два варианта: в начале модуля (почти ничего не отмечено) и в конце (экзамен оценён, показан итог).
3. **Выбор оценки**: вопрос «Оценка известна?», клавиатура `4 5 6 7 / 8 9 10 ✏️ Другая` и «Пока нет».
4. **Экран сданной активности**: текущая оценка, «Изменить оценку», «🗑 Убрать оценку», «↩️ Не сдано», «◀️ К предмету».
5. **Ввод оценки вручную**: приглашение ввести число, подсказка при неверном вводе, подтверждение «Сохранено».
6. **Пустые состояния**: у предмета не задана формула (отметки работают, расчёта нет); у предмета нет активностей.

## Ограничения

- Разметка только Telegram HTML: жирный, курсив, зачёркнутый, моноширинный. Числа накопа удобно выравнивать моноширинным.
- Не больше одной эмодзи на строку. Подпись кнопки предмета до ~28 символов, кнопки активности до ~14.
- Экран предмета без прокрутки при 8–10 активностях.
- Значки должны совпадать с разделом «Дедлайны», чтобы активность выглядела одинаково в обоих местах.

## Что сдать

- 6 макетов с указанными вариантами.
- Дополнение к легенде эмодзи: значок «Проекта», статусы `☐ / ✅ / ✅ 8.5`, значок накопа и итога.
