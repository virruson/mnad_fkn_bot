# UI: «Обратная связь»

Макеты текстов бота для задачи `feedback_designer.md`. Разметка — Telegram HTML (`parse_mode=HTML`): `<b>`, `<i>`, `<code>`, `<blockquote>`.
Кнопки обозначены `[ … ]`; кнопки в одной строке стоят рядом: `[ A ] [ B ]`.
Пример построен на дате ср 14.10.2026. Имена и цифры в примерах — образец.
Тексты и разметку переносить дословно.

## Общие правила

- Стиль тот же, что в `ui_deadlines.md` и `ui_progress.md`: не больше одной эмодзи на строку, возврат `◀️ Назад`, пустое состояние `<i>нет информации</i>`.
- Бот говорит о человеке, который его ведёт, в третьем лице: «автор». Не «я», не «администратор», не «поддержка».
- Обращение к студенту на «вы», коротко, без канцелярита.
- Текст студента у автора и ответ автора у студента — всегда в `<blockquote>`. Внутри — как прислали: переносы строк и эмодзи сохраняются, HTML экранируется.
- Числа без склонений: «1254 из 1000 символов», «всего 24». Так не нужны правила множественного числа.
- Экраны ввода и ошибок ввода — это «экран» (`show_screen`). Ответ автора студенту и сообщения автору — фоновые сообщения, остаются в чате.

## 1. Главное меню

```
[ 📅 Расписание ] [ 🔔 Уведомления ]
[ ⏳ Дедлайны ] [ 📈 Мой прогресс ]
[ 💬 Обратная связь ] [ 🚪 Выйти ]
```
- Значок раздела «Дедлайны» — как сейчас в коде.
- Если `FEEDBACK_CHAT_ID` не задан, третья строка — только `[ 🚪 Выйти ]`, как сейчас.

## 2. Экран «💬 Обратная связь»

### Вариант А — студент ещё не говорил спасибо

```html
💬 <b>Обратная связь</b>
Нашли ошибку в сроках или есть идея? Напишите — автор бота прочитает и ответит прямо здесь.
```
```
[ 🤍 Спасибо · 23 ]
[ ✏️ Написать ]
[ ◀️ Назад ]
```

### Вариант Б — уже сказал спасибо

```html
💬 <b>Обратная связь</b>
Нашли ошибку в сроках или есть идея? Напишите — автор бота прочитает и ответит прямо здесь.
```
```
[ ❤️ Спасибо · 24 ]
[ ✏️ Написать ]
[ ◀️ Назад ]
```

- 🤍 — студент ещё не говорил спасибо, ❤️ — уже сказал. Работает как ☐ / ✅ у переключателей: меняется только значок и число, подпись та же.
- Число — сколько студентов всего сказали спасибо. Если пока 0 — `[ 🤍 Спасибо ]` без числа.
- Текст экрана в обоих вариантах одинаковый.

Всплывающие подсказки (`query.answer`):

| Когда | Текст |
|---|---|
| первое нажатие «🤍 Спасибо» | `Спасибо дошло до автора ❤️` |
| повторное нажатие «❤️ Спасибо» | `Ваше спасибо уже засчитано` |

После первого нажатия экран перерисовывается в вариант Б.

## 3. Ввод сообщения

### Вариант А — из экрана «Обратная связь»

```html
✏️ <b>Сообщение автору</b>
Напишите одним сообщением, до 1000 символов. Например:
<i>«По RecSys срок ДЗ №1 перенесли на 21.10, 23:59»</i>

Автор увидит ваше имя и почту.
/cancel — отмена
```

### Вариант Б — из карточки предмета («✏️ Неточность?»)

```html
✏️ <b>Неточность: RecSys</b>
Что не так в сроках или заданиях? Напишите одним сообщением, до 1000 символов. Например:
<i>«Срок ДЗ №1 перенесли на 21.10, 23:59»</i>

Автор увидит ваше имя и почту.
/cancel — отмена
```
- В заголовке — короткое название предмета, как на кнопках.
- `/cancel` → туда, откуда пришли: экран «Обратная связь» или карточка предмета.

### Вариант В — из ответа автора («✏️ Ответить», см. п. 6)

```html
✏️ <b>Ответ на обращение №12</b>
Напишите одним сообщением, до 1000 символов.

Автор увидит ваше имя и почту.
/cancel — отмена
```
- `/cancel` → главное меню.

### Кнопка в карточке предмета

Карточка в «Дедлайнах», под текстом:
```
[ ✏️ Неточность? ]
[ ◀️ Назад ]
```
- В карточке «Моего прогресса» этой кнопки нет.

## 4. Ошибки ввода

Экран ввода заменяется ошибкой, бот ждёт новое сообщение. Заголовок — тот же, что был на экране ввода (`Сообщение автору` / `Неточность: RecSys` / `Ответ на обращение №12`).

Слишком длинно:
```html
✏️ <b>Сообщение автору</b>
Слишком длинно: 1254 из 1000 символов. Сократите и отправьте ещё раз.
/cancel — отмена
```

Прислали не текст (фото, стикер, голосовое, файл):
```html
✏️ <b>Сообщение автору</b>
Принимается только текст. Если хотели показать скриншот — опишите словами, что на нём.
/cancel — отмена
```

Лимит на сутки исчерпан (показывается сразу вместо экрана ввода, ничего не ждём):
```html
💬 <b>Обратная связь</b>
За сутки можно отправить 5 сообщений, лимит исчерпан. Следующее — после 18:40.
```
```
[ ◀️ Назад ]
```
- Время — когда самое старое из 5 сообщений выйдет из окна 24 часов, МСК: `после 18:40`, а если это уже завтра — `завтра после 18:40`.
- `◀️ Назад` → туда, откуда пришли.

## 5. Отправлено

Из экрана «Обратная связь» и из ответа автора:
```html
✅ <b>Отправлено</b>
Спасибо! Ответ автора придёт сюда, в этот чат.
```
```
[ 🏠 Главное меню ]
```

Из карточки предмета:
```html
✅ <b>Отправлено</b>
Спасибо! Ответ автора придёт сюда, в этот чат.
```
```
[ ◀️ К предмету ]
[ 🏠 Главное меню ]
```
- Текст студента не повторяем: его сообщение и так осталось в чате выше.

## 6. Ответ автора студенту

Фоновое сообщение, остаётся в чате:
```html
💬 <b>Ответ автора</b>
На ваше сообщение от 12.10: <i>«привет! во первых хотела сказать спасибо за бота…»</i>

<blockquote>Спасибо! Квизы по временным рядам разделил, срок ДЗ №1 по RecSys перенёс на 21.10.</blockquote>
```
```
[ ✏️ Ответить ]
```
- Цитата — первые 50 символов обращения, обрезка по слову с «…», без переносов строк.
- `✏️ Ответить` открывает ввод (п. 3, вариант В). Кнопка остаётся под сообщением — можно ответить и позже.
- Несколько ответов на одно обращение — несколько таких сообщений, каждое со своей кнопкой.

## 7. Что видит автор

Служебные сообщения в чате `FEEDBACK_CHAT_ID`.

### Новое обращение

```html
💬 <b>Обращение №12</b>
Анна Смирнова · @anna_smr · asmirnova@edu.hse.ru
Откуда: Дедлайны · RecSys

<blockquote>привет! во первых хотела сказать спасибо за бота мнад, правда очень удобно!! а во вторых у меня есть несколько предложений 👉🏻👈🏻
…</blockquote>
<i>Ответьте на это сообщение (reply), чтобы ответить студенту.</i>
```
- Строка «Откуда»:
  - `Обратная связь` — из главного меню;
  - `Дедлайны · <короткое название>` — из карточки предмета;
  - `ответ на №12` — из кнопки «✏️ Ответить».
- Нет @username — строка без него: `Анна Смирнова · asmirnova@edu.hse.ru`.
- Сообщение со звуком.

### Спасибо

```html
❤️ Спасибо · Анна Смирнова (@anna_smr) · всего 24
```
- Без звука (`disable_notification=True`). Одна строка, без кнопок.

### Доставка ответа

- Доставлено — реакция 👍 на ответ автора. Если реакции недоступны — короткий reply `✓ доставлено`.
- Не доставлено:
```html
⚠️ Не доставлено: студент заблокировал бота
```
- Reply не на обращение — бот молчит.

## Легенда (дополнение к `ui_deadlines.md` и `ui_progress.md`)

| Значок | Где | Значение |
|---|---|---|
| 💬 | меню, заголовки | раздел «Обратная связь», ответ автора, обращение у автора |
| 🤍 | кнопка | спасибо ещё не сказано |
| ❤️ | кнопка, подсказка, у автора | спасибо сказано / новое спасибо |
| ✏️ | кнопки, заголовок ввода | написать, сообщить о неточности, ответить (то же, что «ввести оценку» в прогрессе: «ввести текст») |
| ✅ | заголовок | отправлено |
| ⚠️ | у автора | ответ не доставлен |
| 👍 | реакция у автора | ответ доставлен |
