# Задача 2. Объявления о новинках — промт для разработчика

## Контекст

Telegram-бот `mnad_fkn_bot`: Python (python-telegram-bot), PostgreSQL, SQLAlchemy/Alembic.

**Зависимость:** делается после задачи «Дедлайны и уведомления» (`deadlines_developer.md`). Там меню уведомлений переделано на переключатели.

**Зачем:** когда в боте появляется что-то новое (новый раздел или предмет, например ВКР), нужно сообщить об этом всем пользователям. Рассылка запускается вручную командой админа. Автоматическую рассылку при импорте не делаем: импорт запускается часто и правит опечатки, получится шум.

## 1. Данные (миграция)

- `users.news_enabled BOOL NOT NULL DEFAULT true`.
- `announcements`: `id, text, button, sent_at, delivered, failed`.

## 2. Доступ

- В `.env` добавить `ADMIN_IDS`: список telegram_id через запятую.
- Если `/announce` отправляет не админ, бот молча игнорирует команду.

## 3. Сценарий `/announce` (ConversationHandler)

1. Админ присылает текст объявления. Разрешена HTML-разметка.
2. Бот предлагает выбрать кнопку перехода: «⏰ Дедлайны» / «📅 Расписание» / «🔔 Уведомления» / «Без кнопки». Callback кнопки ведёт в существующий раздел.
3. Бот показывает превью ровно в том виде, в каком его получат пользователи.
4. Под превью кнопки «✅ Отправить всем (N чел.)» и «✖️ Отмена».
5. После нажатия «Отправить» эта кнопка сразу деактивируется, чтобы двойной клик не отправил объявление дважды.

Шаблон сообщения:

```
📣 Новое в боте
<текст админа>
[кнопка перехода, если выбрана]
```

## 4. Рассылка

- Получатели: `is_verified = true AND news_enabled = true`.
- Между отправками пауза около 0.05 с, чтобы не упереться в лимиты Telegram.
- `Forbidden` (пользователь заблокировал бота) и прочие ошибки логируются и считаются, рассылка продолжается.
- После рассылки админ получает отчёт «Доставлено X, ошибок Y», результат сохраняется в `announcements`.
- Объявление приходит отдельным фоновым сообщением, мимо `show_screen`.

## 5. Переключатель в меню уведомлений

- В список переключателей из задачи 1 добавить четвёртый: «Новости бота» → `news_enabled`.

## 6. Подсказка в импорте

- В конце работы `import_schedule.py` и `import_deadlines.py` выводят строку «Новые предметы: …». Это напоминание админу, что новинку стоит объявить. Сами скрипты ничего не рассылают.

## Критерии готовности

- `/announce` недоступен тем, кого нет в `ADMIN_IDS`.
- Превью совпадает с тем, что получают пользователи.
- Двойной клик по «Отправить» не приводит к повторной рассылке.
- Пользователи с выключенными «Новостями бота» объявление не получают.
- Админ получает отчёт, запись есть в `announcements`.
- Тексты взяты из макета дизайнера (`announcements_designer.md`).
