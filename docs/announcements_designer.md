# Задача 2. Объявления о новинках — промт для дизайнера

## Контекст

Telegram-бот расписания магистратуры ВШЭ (МНАД). Интерфейс состоит только из текста, эмодзи и inline-кнопок. Нужен минимализм, всё должно читаться на телефоне. Стиль, вид переключателей и легенда эмодзи берутся из задачи «Дедлайны и уведомления» (`deadlines_designer.md`).

**Зачем:** админ вручную рассылает всем пользователям короткое объявление о новинке в боте, например «появилась ВКР».

## Нужно сделать

1. **Шаблон объявления** в двух вариантах:
   - с кнопкой «⏰ Открыть дедлайны», пример: «В разделе „Дедлайны“ появилась ВКР: сроки этапов и требования к оценке»;
   - без кнопки.

   Заголовок: «📣 Новое в боте», после него 1–2 строки текста. Первая строка должна быть понятна в push-уведомлении.
2. **Экраны админа** (видит только админ):
   - просьба прислать текст;
   - выбор кнопки перехода: Дедлайны / Расписание / Уведомления / Без кнопки;
   - превью, под ним «✅ Отправить всем (N чел.)» и «✖️ Отмена»;
   - отчёт: «Доставлено X, ошибок Y».
3. **Четвёртый переключатель** в меню уведомлений: «Новости бота», оформленный в том же стиле, что и три существующих.

## Ограничения

- Разметка только Telegram HTML.
- Подпись кнопки не длиннее ~28 символов.
- Не больше одной эмодзи на строку.
