# График дедлайнов — макет дизайнера

Макет: `deadline_chart_mock.png` (данные на 06.10.2026 из `scripts/deadlines.json`).
Задача: `deadline_chart_designer.md`.

## Что на картинке

- **Окно:** сегодня + 14 дней, включительно (06.10 – 20.10, 15 дней на шкале). Прошедшие дедлайны не показываются. Исключение — дедлайн, у которого основной срок прошёл, а жёсткий ещё нет: он показан (см. «Штраф»).
- **Строка = дедлайн.** Сверху подпись, под ней полоса. Сортировка по актуальному сроку (для штрафных — по жёсткому), при равенстве — по названию предмета.
- **Подпись:** `Короткое название · что сдать` слева, дата справа одной колонкой по правому краю. Колонка дат одинакова для всех строк и не зависит от длины полосы, поэтому длинные подписи вроде «20.10 → 25.10» всегда помещаются.
  - Если подпись не влезает до колонки дат — обрезать по слову с «…».
  - Эмодзи на картинке не используются (matplotlib не рисует цветные эмодзи). Если в `short_name` есть эмодзи (например, «📜 ВКР»), на картинке его убрать.
- **Дата:** `11.10`; со временем, если оно не 23:59: `26.10, 18:10`. Срочные (сегодня/завтра) — словом `сегодня` / `завтра`, жирным, основным цветом текста. Это заменяет «❗» на картинке.
- **Полоса:** от линии «сегодня» до срока, на конце маркер типа.
- **Штраф** (есть жёсткий срок): основная полоса до основного срока, дальше заштрихованная часть до жёсткого срока. Подпись даты `20.10 → 25.10`.
  - Основной срок уже прошёл: вся видимая полоса заштрихована, маркер на жёстком сроке (`04.10 → 11.10`).
  - Жёсткий срок за окном: штриховка обрезается краем шкалы, маркер на основном сроке, полный диапазон — в подписи.
- **Ориентировочно:** полоса пунктиром, перед датой `~` (`~20.10`).
- **Сегодня:** красная вертикальная линия на всю высоту, над ней подпись «сегодня» (белым, жирным).
- **Выходные:** фоновые полосы на всю высоту.
- **Шкала:** засечка на каждый день, подписи только у «сегодня» и понедельников (`пн 12.10`).
- **Легенда** под заголовком: только типы и стили, которые есть на картинке, в фиксированном порядке: ДЗ, Квиз/КР, КР, Экзамен, Этап ВКР, штраф, ориентир.
- **Заголовок:** «Дедлайны на 2 недели», справа диапазон `06.10 – 20.10`.
- **Максимум 11 строк.** Остальные дедлайны окна уходят в подпись к фото: «и ещё N до 20.10».

## Цвета и второй признак

Пять разных цветов на одном графике не проходят проверку на дальтонизм: любые типы стоят рядом. Поэтому цветов три (проверены валидатором для тёмного фона, все пары), а тип внутри цвета различается маркером и текстом в подписи.

| Тип | Цвет | Маркер на конце полосы |
|---|---|---|
| ДЗ | `#3987e5` синий | ● круг |
| Квиз, Квиз/КР | `#c98500` жёлтый | ◆ ромб |
| КР | `#c98500` жёлтый | ■ квадрат |
| Экзамен | `#c98500` жёлтый | ★ звезда |
| Этап ВКР | `#199e70` бирюзовый | ▲ треугольник |

Смысл цветов: синий — домашняя работа, жёлтый — контроль в аудитории, бирюзовый — ВКР. Оранжевый и красный для типов не берём: они сливаются с линией «сегодня».

| Роль | HEX |
|---|---|
| Фон | `#1a1a19` |
| Выходные | `#232321` |
| Ось, засечки | `#383835` |
| Текст основной (подписи, «сегодня», срочные даты) | `#ffffff` |
| Текст вторичный (даты, легенда, диапазон) | `#c3c2b7` |
| Текст приглушённый (подписи шкалы) | `#898781` |
| Линия «сегодня» | `#d03b3b` |

## Размеры (px, холст 1080 по ширине)

| Элемент | Значение |
|---|---|
| Ширина | 1080 |
| Высота | 240 + 92 × строк + 48; не меньше 720, не больше 1350 |
| Поля | 48 со всех сторон |
| Заголовок | 44, жирный |
| Подписи строк, даты | 32 |
| Легенда, диапазон, шкала | 28 |
| Шрифт | DejaVu Sans |
| Отступы сверху вниз | заголовок → 24 → легенда (строка 28) → 40 → подписи шкалы (28) → 28 → первая строка |
| Шаг строки | 92 |
| Полоса | высота 18, скругление 4; от подписи до центра полосы 50 |
| Маркер | 16 (треугольник 20, звезда 24), обводка цветом фона 3 |
| Пунктир | 40 штрих / 16 пробел |
| Штриховка | линии 45° цветом типа по фону, сверху и снизу контур 2 цветом типа |
| Линия «сегодня» | 3 |
| Ось | 2, засечки 10 |

При показе в Telegram картинка ужимается примерно в 3 раза, поэтому кегль 32 для подписей — минимум, меньше не делать.

## Подпись к фото (Telegram HTML)

```html
❗ <b>Ближайший:</b> Временные ряды — квиз/КР №7–8, завтра
<b>Позже:</b>
Глубинное обучение — ДЗ №1 · 25.10
Алгоритмы и СД — экзамен · 26.10, 18:10
Продвинутое МО — экзамен · 31.10, 14:40
<i>и ещё 13 — в карточках предметов</i>
```
- Формат строки тот же, что в утренней рассылке: `Короткое название — что сдать`.
- «❗» в первой строке — только если ближайший дедлайн сегодня или завтра. Дата у ближайшего: `сегодня` / `завтра` / `осталось N дн`.
- «Позже» — дедлайны после окна, максимум 3 строки, остальные — строкой «и ещё N — в карточках предметов». Нет таких — блок не выводится.
- Если в окне больше 11 дедлайнов, после «Ближайшего» добавляется строка `<i>и ещё N до 20.10 — не поместились на график</i>`.

Пустое окно — картинка не отправляется, текстовый экран:
```html
⏰ <b>Дедлайны на 2 недели</b>
<i>нет информации</i>

<b>Позже:</b>
Глубинное обучение — ДЗ №1 · 25.10
```
(блок «Позже» — по тем же правилам, если есть что показать).

## Допущение в макете

В данных нет ориентировочных дедлайнов, поэтому для показа пунктира этап ВКР «Выбор научных руководителей» в макете отмечен как ориентировочный. В реальных данных он обычный.
