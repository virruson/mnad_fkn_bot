# UI: дедлайны, карточка предмета, уведомления, объявления

Макеты текстов бота. Разметка — Telegram HTML (`parse_mode=HTML`): `<b>`, `<i>`, `<s>`, `<code>`.
Кнопки обозначены `[ … ]`, по одной в строке. Пример построен на дате сб 03.10.
Тексты и разметку переносить дословно; данные в примерах — образец.

## Общие правила

- Срочно: до дедлайна меньше 2 дней (сегодня или завтра) → «❗» на кнопке предмета и в строке дедлайна.
- Остаток: «осталось N дн», в день дедлайна — «сегодня». Дни считаются по календарным датам МСК.
- Прошедший дедлайн зачёркивается целиком (`<s>`), остаток не пишется.
- Время дедлайна пишется, только если оно не 23:59.
- Формула: `Итог = 0.3·ДЗ + 0.2·Квизы + 0.5·КР` (в `<code>`).
- Пустое состояние везде: `<i>нет информации</i>`.
- Не больше одной эмодзи на строку, кнопки в один столбец.
- В подписях кнопок HTML не работает: срочность на кнопке показывает только «❗».

## 1. Экран «⏰ Дедлайны»

```html
⏰ <b>Дедлайны</b>
Выберите предмет · ❗ — меньше 2 дней
```
```
[ ❗ Продвинутое МО ]
[ Базы и хранилища данных ]
[ Временные ряды ]
[ Обучение с подкреплением ]
[ ВКР ]
[ 🏠 Главное меню ]
```
- Порядок: предметы с «❗» → остальные по ближайшему будущему дедлайну → предметы без будущих дедлайнов.
- ВКР всегда последняя, над «Главным меню»; при срочном дедлайне получает «❗», но место не меняет.
- Нет предметов: вместо подсказки `<i>нет информации</i>`.

## 2. Карточка предмета

Вариант А — с дедлайнами:
```html
<b>Продвинутое машинное обучение</b>

📝 <b>ДЗ</b>
<s>№1 · 26.09</s>
❗ №2 · 04.10 · <b>осталось 1 дн</b>
№3 · 17.10 · осталось 14 дн

🧠 <b>Квизы</b>
<s>№1 · 30.09</s>
❗ №2 · 03.10, 18:00 · <b>сегодня</b>
№3 · 10.10 · осталось 7 дн

📋 <b>КР</b>
№1 · 24.10 · осталось 21 дн

🧮 <b>Формула</b>
<code>Итог = 0.3·ДЗ + 0.2·Квизы + 0.5·КР</code>
```
```
[ ◀️ Назад ]
```

Вариант Б — пустая:
```html
<b>Обучение с подкреплением</b>

<i>нет информации</i>
```
```
[ ◀️ Назад ]
```

Карточка ВКР (этапы вместо блоков, без формулы):
```html
<b>ВКР</b>

<s>25.09 · Заявка на тему</s>
07.10 · Тема и руководитель · осталось 4 дн
20.04 · Предзащита · осталось 199 дн
```
```
[ ◀️ Назад ]
```

- Строка: `№ · дата · остаток`. У этапов ВКР дата впереди: `дата · этап · остаток` (названия этапов длинные). Тип задания не повторяется, его называет заголовок блока.
- Порядок блоков: 📝 ДЗ, 🧠 Квизы, 📋 КР, 🎓 Экзамен, 🧮 Формула. Внутри блока — по дате.
- Если в таблице курса квизы и КР в одной колонке, блок называется «🧠 Квизы/КР», а отдельный блок КР не выводится. Блок КР показывается, только если в нём есть дедлайны.
- У ВКР один блок «📌 Этапы» (заголовок можно не выводить, если других блоков нет), формулы нет.
- «❗» и жирный остаток — только в срочных строках.
- Пустой блок: заголовок + `<i>нет информации</i>`. Пусты все четыре блока → одна строка, как в варианте Б.
- Без прокрутки: в блоке максимум 4 строки. Лишние — самые старые прошедшие — скрываются, в конце блока `<i>ещё N прошедших</i>`.
- Заголовок карточки — полное название, без эмодзи.

## 3. Меню «🔔 Уведомления»

```html
🔔 <b>Уведомления</b>
Включено 3 из 4
```
```
[ ✅ Расписание на день · 10:00 ]
[ ✅ Напоминание за 15 мин ]
[ ✅ Дедлайны · за 4, 2, 1 дн ]
[ ☐ Новости бота ]
[ 👥 Группа: 1 поток ]
[ 🏠 Главное меню ]
```
- ✅ — вкл, ☐ — выкл. Подпись не меняется, меняется только значок.
- Нажатие сразу правит сообщение; всплывающая подсказка: «Новости бота: вкл» / «…: выкл».
- Статус: `Включено N из 4`; всё выключено — `🔕 Все уведомления выключены`; нет группы — `Группа не выбрана`, и любой переключатель сначала открывает выбор группы.
- «👥 Группа: …» открывает выбор группы, после выбора — возврат в это меню.

## 4. Утреннее сообщение о дедлайнах (10:00 МСК)

Один дедлайн:
```html
⏰ <b>Дедлайны</b>

❗ <b>Завтра</b> · вс 04.10
Продвинутое МО — ДЗ №2
```

Пять дедлайнов:
```html
⏰ <b>Дедлайны</b>

❗ <b>Завтра</b> · вс 04.10
Продвинутое МО — ДЗ №2
Теорвер и матстат — квиз №4

<b>Через 2 дня</b> · пн 05.10
Базы и хранилища данных — КР №1

<b>Через 4 дня</b> · ср 07.10
Временные ряды — ДЗ №2
ВКР — тема и руководитель
```
```
[ ⏰ Открыть дедлайны ]
```
- Группы: ровно через 1, 2 и 4 дня. Пустые группы не выводятся; нет дедлайнов — сообщение не отправляется.
- «❗» только у группы «Завтра».
- Строка: `Короткое название — тип №` (для ВКР — `ВКР — этап`). Тип строчными: ДЗ, квиз, КР.
- Сообщение остаётся в чате (не «экран»).

## 5. Объявление «📣 Новое в боте»

С кнопкой:
```html
📣 <b>Новое в боте</b>

В разделе «Дедлайны» появилась <b>ВКР</b>:
все этапы и сроки в одном месте.
```
```
[ ⏰ Открыть дедлайны ]
```

Без кнопки:
```html
📣 <b>Новое в боте</b>

Напоминание за 15 мин теперь можно
выключить отдельно от расписания.
```
- Заголовок фиксирован, затем пустая строка, затем 1–2 строки текста (~80 символов).
- Жирным — только одно ключевое слово. Эмодзи в тексте нет, разделы — в кавычках.
- Кнопка необязательна, одна: `<значок раздела> Открыть <раздел>`.
- Получают только пользователи с включёнными «Новостями бота». Сообщение остаётся в чате.

## Правило сокращения названий (кнопки и рассылка)

Лимит названия — 25 символов (+ «❗ » = 28).
1. ≤ 25 символов — без сокращения.
2. Длиннее — поле `short_name` предмета:
   - Продвинутое машинное обучение → Продвинутое МО
   - Теория вероятностей и математическая статистика → Теорвер и матстат
   - Анализ и прогнозирование временных рядов → Временные ряды
   - Глубинное обучение и нейронные сети → Глубинное обучение
   - Алгоритмы и структуры данных → Алгоритмы и СД
   - НИС «Продуктовый подход в аналитике данных» → НИС Продуктовая аналитика
3. `short_name` пуст — обрезка по границе слова до 24 символов + «…».

Полное название — только в заголовке карточки.

## Легенда эмодзи

| Значок | Значение |
|---|---|
| ⏰ | Дедлайны: раздел, рассылка, кнопка перехода |
| ❗ | до дедлайна меньше 2 дней |
| 📝 | ДЗ |
| 🧠 | Квизы |
| 📋 | КР |
| 🎓 | Экзамен |
| 📌 | Этапы (ВКР) |
| 🧮 | Формула |
| 🔔 / 🔕 | Уведомления / все выключены |
| ✅ / ☐ | вкл / выкл |
| 👥 | группа |
| 📣 | объявление о новинке |
| ◀️ | назад (внутренние экраны) |
| 🏠 | главное меню |

## Изменения в существующих экранах

- Главное меню: «📚 Задания» → «⏰ Дедлайны», раскладка меню та же.
- «Назад» везде `◀️ Назад` (сейчас в части экранов 🔙).
- Старое меню уведомлений (вкл/выкл одной кнопкой) заменяется экраном 3.
