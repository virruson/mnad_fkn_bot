# UI: дедлайны, карточка предмета, уведомления

Макеты текстов бота в Telegram HTML (`<b>`, `<i>`, `<s>`, `<code>`).
Кнопки обозначены `[ … ]`, по одной на строку. Пример построен на дате ср 30.09.

## Общие правила

- До дедлайна меньше 2 дней (сегодня или завтра) → «❗» на кнопке предмета и в строке дедлайна.
- Остаток: «осталось N дн», в день дедлайна — «сегодня».
- Прошедший дедлайн зачёркивается целиком, остаток не пишется.
- Формула: `Итог = 0.3·ДЗ + 0.2·Квизы + 0.5·КР`.
- Пустое состояние: `<i>нет информации</i>`.
- Не больше одной эмодзи на строку, кнопки в один столбец.
- В подписях кнопок HTML не работает, поэтому срочность на кнопке показывает только «❗».

## 1. Экран «⏳ Дедлайны»

```html
⏳ <b>Дедлайны</b>
Выберите предмет · ❗ — меньше 2 дней
```
```
[ ❗ Продвинутое МО ]
[ Базы и хранилища данных ]
[ Временные ряды ]
[ Обучение с подкреплением ]
[ Алгоритмы и СД ]
[ 🏠 Главное меню ]
```
- Порядок кнопок: сначала предметы с «❗», дальше по ближайшему дедлайну. Предметы без будущих дедлайнов идут в конец.
- Если предметов нет, вместо подсказки выводится `<i>нет информации</i>`.

## 2. Карточка предмета

```html
<b>Продвинутое машинное обучение</b>

📝 <b>ДЗ</b>
<s>№1 · 18.09</s>
❗ №2 · 01.10 · <b>осталось 1 дн</b>
№3 · 15.10 · осталось 15 дн

🧠 <b>Квизы</b>
<s>№1 · 23.09</s>
❗ №2 · 30.09, 18:00 · <b>сегодня</b>
№3 · 07.10 · осталось 7 дн

📋 <b>КР</b>
<i>нет информации</i>

🧮 <b>Формула</b>
<code>Итог = 0.3·ДЗ + 0.2·Квизы + 0.5·КР</code>
```
```
[ ◀️ Назад ]
```
- Формат строки: `№ · дата · остаток`. Тип задания в строке не повторяется, его называет заголовок блока.
- Время пишется, только если дедлайн не в 23:59.
- «❗» и жирный — только в срочных строках.
- Без прокрутки: в блоке максимум 4 строки. Если строк больше, самые старые прошедшие скрываются, в конце блока строка `<i>ещё 2 прошедших</i>`. При 4 строках в каждом блоке карточка занимает около 23 строк.
- Заголовок карточки — полное название предмета, без эмодзи.

## 3. Меню «🔔 Уведомления»

```html
🔔 <b>Уведомления</b>
Включено 2 из 3 · утром в 10:00 МСК
```
```
[ ✅ Расписание на день ]
[ ✅ За 15 мин до пары ]
[ ☐ Дедлайны ]
[ 👥 Группа: 1 поток ]
[ 🏠 Главное меню ]
```
- Вкл/выкл: ✅ / ☐. Подпись кнопки не меняется, меняется только значок.
- Нажатие сразу правит сообщение; `query.answer()` показывает короткое уведомление, например «Дедлайны: вкл».
- Строка статуса в других состояниях:
  - все выключены: `🔕 Все уведомления выключены`;
  - группа не выбрана: `Группа не выбрана`. Нажатие на любой переключатель сначала открывает выбор группы.

## 4. Утреннее сообщение о дедлайнах

Один дедлайн:
```html
⏳ <b>Дедлайны</b>

❗ <b>Завтра</b> · чт 01.10
Продвинутое МО — ДЗ №3
```

Пять дедлайнов:
```html
⏳ <b>Дедлайны</b>

❗ <b>Завтра</b> · чт 01.10
Продвинутое МО — ДЗ №3
Теорвер и матстат — квиз №4

<b>Через 2 дня</b> · пт 02.10
Базы и хранилища данных — КР №1

<b>Через 4 дня</b> · вс 04.10
Временные ряды — ДЗ №2
Обучение с подкреплением — квиз №1
```
```
[ ⏳ Все дедлайны ]
```
- Пустые группы не выводятся. Если дедлайнов нет, сообщение не отправляется.
- «❗» только у группы «Завтра».
- Оба варианта собираются по одному шаблону.

## Правило сокращения названий

На название отводится 25 символов: ещё 3 уходят на «❗ » с запасом, итого 28.

1. До 25 символов включительно — без сокращения: «Базы и хранилища данных» (23).
2. Длиннее — ручное сокращение из поля `short_name` предмета:
   - «Продвинутое машинное обучение» → Продвинутое МО
   - «Теория вероятностей и математическая статистика» → Теорвер и матстат
   - «Анализ и прогнозирование временных рядов» → Временные ряды
   - «Глубинное обучение и нейронные сети» → Глубинное обучение
   - «Алгоритмы и структуры данных» → Алгоритмы и СД
   - НИС «Продуктовый подход в аналитике данных» → НИС Продуктовая аналитика
3. `short_name` пуст — обрезка по границе слова до 24 символов и «…» в конце.

Короткое имя — на кнопках и в утреннем сообщении. Полное — только в заголовке карточки.

## Легенда эмодзи

| Значок | Значение | Где |
|---|---|---|
| ⏰ | время пары | расписание, напоминания (без изменений) |
| ⏳ | дедлайны | раздел, утреннее сообщение |
| ❗ | до дедлайна меньше 2 дней | кнопка предмета, строка дедлайна, группа «Завтра» |
| 📝 | ДЗ | карточка |
| 🧠 | Квизы | карточка |
| 📋 | КР | карточка |
| 🧮 | Формула | карточка |
| 🔔 / 🔕 | уведомления / все выключены | меню, статус |
| ✅ / ☐ | вкл / выкл | переключатели |
| 👥 | группа | кнопка группы |
| ◀️ | назад | внутренние экраны |
| 🏠 | главное меню | корневые экраны |

## Решения по текущему коду

- ⏰ остаётся за временем пары в расписании; для дедлайнов — ⏳.
- «Назад» везде `◀️ Назад` (заменить 🔙 в `schedule.py`, `tasks.py`, `subjects.py`).
- Кнопка «📚 Задания» в главном меню заменяется на «⏳ Дедлайны», значок 📚 больше не используется.
