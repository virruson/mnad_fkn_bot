# mnad_fkn_bot

Как это работает:

1. При первом запуске (/start):

2. Показывается приветствие с описанием функций.
   Только одна кнопка "🔐 Авторизоваться"

3. При нажатии на кнопку авторизации:
   Запускается процесс ввода email
   Отправляется код на почту
   Пользователь вводит код

4. После успешной авторизации:
   Автоматически показывается полное меню со всеми функциями
   При следующих запусках /start сразу показывает полное меню

5. Без авторизации:
   Все остальные кнопки скрыты
   При попытке вызвать команду напрямую - предложение авторизоваться
